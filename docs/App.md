Behavior-Based Roommate Matching Web App
Empathize
● Sleep Cycle Friction: Early risers vs. late-night gamers create daily noise disruptions.
● Cleaning Standard Mismatch: Inconsistent chore habits and unwashed dishes lead to
shared-space conflicts.
● Screening Discomfort: Users avoid asking direct personal questions (guest rules,
smoking, pet habits) in initial chats.
Define

● Renters need habit screening before signing leases because daily routine mismatches
break co-living arrangements.
● Room posters need pre-filtered applicant data because sorting unstructured social media
messages is inefficient.
● Privacy-oriented tenants need clear upfront living boundaries to avoid direct roommate
confrontations.
Ideate

1. Behavioral Compatibility Matcher: 2-minute lifestyle quiz (sleep, cleaning, guests,
noise) generating a % Compatibility Score.
2. Deal-Breaker Filter Board: Profiles unlock only after both parties accept mutual
non-negotiable house rules.
3. Visual Weekly Routine Matrix: Side-by-side schedule cards highlighting overlapping
active and quiet hours.
Chosen Solution: Behavioral Compatibility Matcher
Why
● Core Problem Fit: Directly targets lifestyle compatibility rather than just price and room
photos.
● Organic Growth: High user incentive to share profile match links in housing groups and
community boards.
● Scalable & Repeatable: The same matching system can be reused across different
cities, universities, and rental markets, while users may return whenever they need a
new roommate or replace an existing one. This creates a continuously evolving user
base without requiring major changes to the core website.

App - Behavior based Roommate Matching Web App

MVP Features

- **Habit & Lifestyle Quiz** - Take a 2-minute lifestyle assessment to log sleep hours, cleanliness habits, and guest rules.
- **Compatibility Match Score** - View a % match score and habit tags on profiles to instantly spot living compatibility.
- **Filtered Roommate Directory** - Search and filter candidate profiles by budget, location, and minimum match percentage.
- **1-on-1 Direct Chat** - Message high-compatibility matches directly to discuss room details and arrange meetups.
